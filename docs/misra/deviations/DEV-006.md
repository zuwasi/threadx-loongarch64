# DEV-006: Functions implemented in assembly have no C definition

| Field | Value |
|---|---|
| Deviation ID | DEV-006 |
| Guideline | Rule 8.6 (Required): An identifier with external linkage shall have exactly one external definition |
| Parasoft checkers | MISRAC2025-RULE_8_6-b |
| Status | Draft (approval pending) |
| Scope | Project-wide |
| Requirement(s) | LA-REQ-002, LA-REQ-102, LA-REQ-104, LA-REQ-105, LA-REQ-106 |

## 1. Locations

| File | Function or symbol |
|---|---|
| `ports/loongarch64/gnu/inc/tx_port.h` | `_tx_thread_interrupt_control` (defined in `src/tx_thread_interrupt_control.S`) |
| `bsp/qemu_virt/inc/bsp.h` | `bsp_cpucfg_read`, `bsp_timer_config_write`, `bsp_timer_ack`, `bsp_irq_line_enable`, `bsp_irq_line_disable`, `bsp_crmd_read`, `bsp_ecfg_read`, `bsp_estat_read`, `bsp_era_read`, `bsp_badv_read`, `bsp_cpu_idle`, `bsp_cpu_halt`, `bsp_exception_entry_set` (defined in `src/bsp_cpu.S`) |
| `test/bringup/bringup.h` | `bringup_trap_entry` (defined in `bringup_trap.S`), `bringup_trigger_break` (defined in `bringup_break.S`) |

## 2. Reason for the deviation

Per the GEP (Dir 4.3), all control and status register access is confined to
assembly; the port and BSP functions that touch CSRs are therefore written in
`.S` files. The C whole-program model of the static analyser contains only C
compilation units, so it cannot see the assembly definitions and reports the
declarations as undefined. The definitions exist and are linked into every
image.

## 3. Risk analysis

- **Hazard addressed by the guideline:** a declared function without a
  definition leads to an unresolved reference or to unexpected code being
  bound at link time.
- **Why it cannot occur here:** every listed function is implemented in
  exactly one assembly source and assembled into the same static library;
  with `-nostdlib` and no archive scanning surprises, a missing definition
  fails the link. The interfaces are documented in the assembly headers
  (Dir 4.2) and the parameter registers are ABI-identical for the C and
  assembly declarations (LP64D calling convention).
- **Evidence:** `nm` on the linked executables shows exactly one definition
  of each symbol; every function is executed under QEMU: the bring-up test
  covers the CSR accessors, interrupt lines, idle and halt (LA-REQ-002,
  LA-REQ-105), the regression suite covers the timer configuration and
  acknowledge path in six configurations (LA-REQ-102/103), and the fatal
  test covers `bsp_exception_entry_set` and the exception vector
  (LA-REQ-106).

## 4. Compensating measures

- Link map review per release (`docs/safety/tools.md` 3.1).
- Assembly interfaces are reviewed with the port (M3 records) and are
  documented in the `.S` file headers.
