| Status | Draft (approval pending) |

## 1. Locations

| File | Function or symbol |
|---|---|
| `ports/loongarch64/gnu/inc/tx_port.h` | `TX_EVENT_FLAGS_GROUP_CREATE_EXTENSION` (37), `TX_EVENT_FLAGS_GROUP_DELETE_EXTENSION` (37) |
| `ports/loongarch64/gnu/inc/tx_port.h` (regression block) | `TX_MUTEX_PRIORITY_CHANGE_EXTENSION` (34), `TX_THREAD_STACK_ANALYZE_EXTENSION` (33), `TX_INITIALIZE_KERNEL_ENTER_EXTENSION` (36), `threadx_mutex_suspension_put_test` (33), `threadx_mutex_suspension_priority_test` (38), `abort_and_resume_byte_allocating_thread` (39), `abort_all_threads_suspended_on_mutex` (36) |

ESL-owned identifiers that exceeded the limits were renamed or removed
(`TX_LA64_SOLICITED_POSTURE_OFFSET` renamed to `TX_LA64_SOLICITED_PRMD_OFFSET`;
the unused `_tx_version_id` declaration removed), so only ThreadX-mandated
names remain.

## 2. Reason for the deviation

All remaining long identifiers are fixed by upstream sources: the extension
macro names are invoked by the ThreadX kernel, and the regression-hook names
are declared by the upstream regression suite and its port-hook contract.
None can be renamed without modifying `external/threadx` or the upstream
test suite.

## 3. Risk analysis

- **Hazard addressed by the guideline:** a compiler that honours only the
  C90 minimum of 31 significant characters could silently merge distinct
  identifiers.
- **Why it cannot occur here:** the toolchain is pinned (GCC 14.2.0, GNU
  binutils, Ubuntu 24.04). GCC does not truncate identifiers (GCC manual,
  "C Language Standards": supports at least 63 significant characters), and
  ELF symbol tables preserve full names, so merging cannot happen at
  compile or link time.
- **Evidence:** every target builds with `-Werror` and links cleanly with a
  generated map file; the kernel and the 96-test regression suite run on
  these exact names (M4 results).

## 4. Compensating measures

- Toolchain pinning and the GCC LoongArch back-end issue review
  (`docs/safety/tools.md` 3.1).
- The CI build would fail on any symbol collision.
