| Field | Value |
|---|---|
| Deviation ID | DEV-014 |
| Guideline | Dir 4.1 (Required): Run-time failures shall be minimized |
| Parasoft checkers | MISRAC2025-DIR_4_1-b |

## 1. Locations

| File | Symbol |
|---|---|
| `ports/loongarch64/gnu/libc/src/tx_la64_string.c` | the write loop of `memset` |

## 2. Reason for the deviation

The flow analysis reports that the destination pointer `d` of `memset` may
be null at the write `d[i] = value`.  The possibility comes from the
function interface itself: `memset` accepts any pointer value, including
null.

## 3. Risk analysis

- **Hazard addressed by the guideline:** a null pointer dereference at
  run time.
- **Why it cannot occur here:**
  - ISO C99 7.21.6.1 requires the destination to be a valid pointer for
    `n` bytes; `memset(NULL, c, n)` with non-zero `n` is undefined
    behaviour of the *caller*.  The loop writes only while `i < n`, so a
    null destination with `n == 0` (the only defined use of a null
    destination) is never dereferenced.
  - Every call site in this project (kernel `TX_MEMSET`, GCC-generated
    structure initialisation, the regression suite) passes object
    addresses; none passes a null destination.
  - A run-time null guard would turn the undefined caller error into a
    silent no-op, hiding exactly the defect the guideline wants
    detected.  The crash-free guarantee is met by the call-site contract
    above, not by masking the caller defect.
- **Evidence:** the product-scope analysis (Release build) reports no
  Dir 4.1-b finding for this file; the checker fires only in the
  test-harness build (Debug, `-O0`), where the flow analysis is more
  conservative.  The regression suite exercises `memset` heavily in six
  configurations (96/96 tests in each).

## 4. Compensating measures

- The function is covered by the DEV-001 conditions: exact ISO C99
  prototypes, freestanding build, and the CI check that its object has
  no undefined symbols (`tools/check_freestanding_libc.sh`).
- Unit tests of the four functions are planned in milestone M6
  (DEV-001, condition 2).
